Privacy Policy — Kipi & Nooli App

Last updated: October 3, 2026

1. Who this app is for

Kipi & Nooli App is a personal tool used only by its owner to upload videos to the owner's own YouTube channel, "Kipi & Nooli". It is not offered to the public and has no other users.

2. YouTube API Services

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the app accesses

With the owner's permission, granted through Google OAuth, the app accesses only the owner's YouTube channel in order to:

  • read basic channel information (the channel ID), to confirm it is uploading to the correct channel;
  • upload videos and thumbnails, and set or change their title, description, privacy status and scheduled publish time.

The app does not collect, store or process personal data from any other user or viewer. It does not read comments, subscribers or analytics about other people.

4. How data is stored and shared

The OAuth access token is stored only on the owner's own computer and is used only to call the YouTube API. No data is sold, shared with third parties, or used for advertising. The app uses no cookies, analytics or tracking. These web pages only describe the app and collect no data.

5. Revoking access

Access can be revoked at any time from the Google Account security settings: https://security.google.com/settings/security/permissions. Deleting the locally stored token file also removes the app's access.

6. Changes

If this policy changes, the updated version will be published on this page with a new date.
